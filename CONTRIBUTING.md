# Contribuir

Abre un issue con Windows, versión y tipo de instalación de OBS, resolución de cámara y pasos para reproducir. Añade el error de compilación o el registro del motor cuando corresponda; revisa antes que no contengan rutas o datos que no quieras publicar. No subas fotos de otras personas ni credenciales.

Para cambios de maquillaje, conserva los controles y aporta una comparación voluntaria o una prueba sintética. Para transporte e instalación, ejecuta `python -m unittest discover -s tests -v` y prueba en Windows. Las mejoras deben mantener el procesamiento local y la salida de OBS sin textos de control.

Al enviar código, confirma que puedes distribuirlo bajo GPL-2.0-or-later. No se aceptan recursos extraídos de aplicaciones propietarias sin autorización.
